Heap Sort: Builds max heap, repeatedly extracts maximum element <br>

```txt
Elapsed (wall clock) time (h:mm:ss or m:ss): 0:00.00

```

#### InsertionSort.cpp
Insertion Sort: Builds sorted array one element at a time by inserting into correct position <br>
Time: O(n²), Space: O(1) <br>
```txt
Elapsed (wall clock) time (h:mm:ss or m:ss): 0:00.00
Maximum resident set size (kbytes): 3460
```

#### LinearSearch.cpp
Linear Search: Sequentially checks each element until target is found <br>
Time: O(n), Space: O(1) <br>
```txt
Elapsed (wall clock) time (h:mm:ss or m:ss): 0:00.00
Maximum resident set size (kbytes): 3516
```

#### MergeSort.cpp
Merge Sort: Divides array in half, recursively sorts, then merges sorted halves <br>
Time: O(n log n), Space: O(n) <br>
```txt
Elapsed (wall clock) time (h:mm:ss or m:ss): 0:00.00
Maximum resident set size (kbytes): 3520
```

#### QuickSort.cpp
Quick Sort: Picks pivot, partitions array around it, recursively sorts partitions <br>
Time: O(n log n) average, O(n²) worst, Space: O(log n) <br>
```txt
Elapsed (wall clock) time (h:mm:ss or m:ss): 0:00.00
Maximum resident set size (kbytes): 3464
```

#### RadixSort.cpp
Radix Sort: Sorts by processing individual digits using counting sort <br>
Time: O(d * (n + k)) where d is digits, Space: O(n + k) <br>
```txt
Elapsed (wall clock) time (h:mm:ss or m:ss): 0:00.00
Maximum resident set size (kbytes): 3424
```

#### SelectionSort.cpp
Selection Sort: Finds minimum element and places it at the beginning repeatedly <br>
Time: O(n²), Space: O(1) <br>
```txt
Elapsed (wall clock) time (h:mm:ss or m:ss): 0:00.00
Maximum resident set size (kbytes): 3464
```
